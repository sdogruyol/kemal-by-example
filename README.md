# Kemal By Example

This directory contains example projects that will be built with the `Kemal` web framework.

## Shared Stack

- Web framework: `Kemal`
- Database: `SQLite`

## Planned Projects

- Blog
- E-commerce
- Twitter clone
- Todo app
- URL shortener

- `ecommerce/`
